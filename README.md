# Word Sprint

4択クイズで英単語を高速に周回する学習アプリです。iPhone のホーム画面に追加すると、アプリとしてオフラインでも使えます。ビルド不要の静的ファイルだけで動きます。

**▶ https://uekei0612.github.io/word-sprint/**

## iPhone のホーム画面に追加する

1. Safari で上の URL を開きます
2. 共有ボタン →「ホーム画面に追加」

ホーム画面から開くと、ブラウザの枠なしで全画面表示になり、電波が無くても使えます。新しい版を公開すると、次に開いたとき（またはアプリに戻ってきたとき）に「新しいバージョンがあります」が出るので、「更新する」を押してください。

**注意**：ホーム画面のアプリは Safari とは別に学習記録を保存します。Safari で使っていたときの記録は引き継がれません。また、ホーム画面のアイコンを削除すると記録も消えます。

## 学習記録のバックアップ

学習記録はこの端末のブラウザにだけ保存されます。ホームの ⚙（設定）にある「学習記録を書き出す」で、記録・自作デッキ・設定を 1 つのファイル（`word-sprint-backup-YYYYMMDD.json`）に書き出せます。iPhone では共有シートが開くので「"ファイル"に保存」を選んでください。

「学習記録を読み込む」でそのファイルを選ぶと、次のどちらかで取り込めます。

- **統合**：単語ごとに回答数の多い方の記録を残し、自作デッキを足します（同じ中身のデッキは重複させません）。設定は今のまま
- **置き換え**：今の記録・自作デッキ・設定を、ファイルの内容で置き換えます

Safari で使っていた記録をホーム画面のアプリへ移すときも、Safari で書き出してホーム画面のアプリで読み込みます。

## 特徴

- ホームは今のデッキの進み具合とスタートだけ。デッキは「デッキを変更」、設定とバックアップは ⚙ から
- 正解すると自動で次の問題へ。キーボードでも操作できます（`1`〜`4` で回答、`Enter` で次へ、`Esc` で中断）
- 苦手な単語ほど出やすくなります。正誤の記録はブラウザ（localStorage）に保存されます
- 出題方向（英→日／日→英／ミックス）、制限時間、自動発音を切り替えられます
- 内蔵デッキ 7 つ（下の表）
- 自作デッキ：CSV やスプレッドシートの 2 列（英単語・意味）を貼り付けて作成でき、CSV に書き出せます

## 内蔵デッキ

| デッキ | 語数 | 目安 | 例文 |
|---|---|---|---|
| TOEIC 300・基礎（既定） | 150 | TOEIC 400〜600点 | あり |
| TOEIC 300・頻出 | 150 | TOEIC 600〜800点 | あり |
| TOEIC 熟語 | 108 | TOEIC 500〜800点。句動詞・成句 | あり |
| 中学基礎 | 80 | 英検3級 | なし |
| 中上級 | 87 | 英検2級〜準1級 | なし |
| 上級 | 54 | 英検準1級〜1級 | なし |
| IT・エンジニア | 61 | 分野別 | なし |

同じ単語が複数のデッキにあるときは意味の書き方をそろえてあり、学習記録も共有します。4 択の誤答には、正解と語義が一部でも重なる語（「発表する」と「発表する、提示する」など）を出しません。

以前の「TOEIC頻出」は、TOEIC 300 と重なる 66 語を外し、残りを「中上級」にしました。外した語の学習記録は、TOEIC 300 の同じ単語へ引き継ぎます（意味の書き方が違った語も含む）。

## ファイル構成

| ファイル | 中身 |
|---|---|
| `index.html` | 画面の構造（HTML）。読み込む順は `decks/*.js` → `app.js` |
| `style.css` | 見た目（ライト／ダークの配色はファイル冒頭の CSS 変数） |
| `app.js` | アプリ本体。冒頭の `CONFIG` に既定の設定と調整用の値（待ち時間・苦手語の上限・出題の重みなど）をまとめています |
| `decks/*.js` | 内蔵デッキの単語リスト（1 デッキ 1 ファイル） |
| `tools/check-decks.mjs` | 内蔵デッキの検証（形式・重複・意味の書き方・`index.html` と `sw.js` への登録漏れ） |
| `sw.js` | service worker。オフライン用のキャッシュと、新しい版の確認・差し替え |
| `manifest.webmanifest`・`icons/` | ホーム画面アプリの名前・表示方法・アイコン。PNG は `icons/icon.svg` から書き出したもの |

## 内蔵デッキを増やす

1. `decks/` に新しいファイルを作ります（例：`decks/eiken-pre2.js`）。既存のファイルを複製すると楽です。

   ```js
   (window.WORD_SPRINT_DECKS = window.WORD_SPRINT_DECKS || []).push({
     id: 'eiken-pre2', group: 'レベル別', name: '英検準2級', desc: '英検準2級の目安。高校中級の語',
     raw: `
   accomplish|v|成し遂げる
   ...
   `});
   ```

   `raw` は `単語|品詞|意味` 形式の行の並びで、品詞には `n` / `v` / `adj` / `adv` / `phr`（熟語）を使います（空でも構いません）。4 列目以降に `例文|例文の和訳|例文中で強調する語形` を書けます（例：`decks/toeic300-basic.js`。今はまだ画面に出しません）。`id` は学習記録には使わないので後から変えても記録は消えませんが、ほかのデッキと重複させないでください。`desc` は「目安。特徴」の形でそろえています。意味にバッククォート（`` ` ``）は使えません。
2. `index.html` の `<script src="decks/…">` の並びに 1 行足します（`app.js` より前）。この並び順が「デッキを変更」の一覧の表示順になります。`group`（例：`'TOEIC'`）が同じデッキは 1 つの見出しにまとめます。
3. `sw.js` の `FILES` にも足します。足さないとオフラインのときにそのデッキが出ません。
4. `node tools/check-decks.mjs` で確かめます。ほかのデッキにもある単語は、意味の書き方をそろえてください（学習記録のキーは「単語＋意味」なので、書き方が違うと記録が別になります）。

## ローカルで動かす

`index.html` をブラウザで開くだけで動きます（`file://` のままで構いません）。ただし service worker（オフライン動作・更新通知）は `https://` か `localhost` でしか動かないので、それらを試すときは `python3 -m http.server` などで配信してください。CSS・JS・単語リストは `fetch` ではなく `<link>` と `<script>` で読み込んでいるため、サーバーは不要です。持ち出すときは `index.html` だけでなく、`style.css`・`app.js`・`decks/` を同じ場所に置いてください。
