# Word Sprint

4択クイズで英単語を高速に周回する学習アプリです。ビルド不要の HTML 1 ファイルで動きます。

**▶ https://uekei0612.github.io/word-sprint/**

## 特徴

- 正解すると自動で次の問題へ。キーボードでも操作できます（`1`〜`4` で回答、`Enter` で次へ、`Esc` で中断）
- 苦手な単語ほど出やすくなります。正誤の記録はブラウザ（localStorage）に保存されます
- 出題方向（英→日／日→英／ミックス）、制限時間、自動発音を切り替えられます
- 内蔵デッキ：中学基礎 / TOEIC 300・基礎 / TOEIC 300・頻出 / TOEIC頻出 / 上級 / IT・エンジニア
- 自作デッキ：CSV やスプレッドシートの 2 列（英単語・意味）を貼り付けて作成でき、CSV に書き出せます

## ファイル構成

| ファイル | 中身 |
|---|---|
| `index.html` | 画面の構造（HTML）。読み込む順は `decks/*.js` → `app.js` |
| `style.css` | 見た目（ライト／ダークの配色はファイル冒頭の CSS 変数） |
| `app.js` | アプリ本体。冒頭の `CONFIG` に既定の設定と調整用の値（待ち時間・苦手語の上限・出題の重みなど）をまとめています |
| `decks/*.js` | 内蔵デッキの単語リスト（1 デッキ 1 ファイル） |

## 内蔵デッキを増やす

1. `decks/` に新しいファイルを作ります（例：`decks/eiken2.js`）。既存のファイルを複製すると楽です。

   ```js
   (window.WORD_SPRINT_DECKS = window.WORD_SPRINT_DECKS || []).push({
     id: 'eiken2', name: '英検2級', desc: '高校卒業程度',
     raw: `
   accomplish|v|成し遂げる
   ...
   `});
   ```

   `raw` は `単語|品詞|意味` 形式の行の並びで、品詞には `n` / `v` / `adj` / `adv` を使います（空でも構いません）。4 列目以降に `例文|例文の和訳|例文中で強調する語形` を書けます（例：`decks/toeic300-basic.js`。今はまだ画面に出しません）。`id` は学習記録には使わないので後から変えても記録は消えませんが、ほかのデッキと重複させないでください。意味にバッククォート（`` ` ``）は使えません。
2. `index.html` の `<script src="decks/…">` の並びに 1 行足します（`app.js` より前）。この並び順がホームの表示順になります。

## ローカルで動かす

`index.html` をブラウザで開くだけで動きます（`file://` のままで構いません）。CSS・JS・単語リストは `fetch` ではなく `<link>` と `<script>` で読み込んでいるため、サーバーは不要です。持ち出すときは `index.html` だけでなく、`style.css`・`app.js`・`decks/` を同じ場所に置いてください。
